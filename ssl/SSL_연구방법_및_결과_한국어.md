# 외부 자가지도학습(SSL) 생체 신호 피처 추출 및 결합 방법론 (의공학회지 보완용)

> 본 문서는 교수님 피처 피드백 (2)번 사항(**"외부 자가지도학습(SSL) 신호 피처가 정확히 무엇인지: 사용 데이터, 모델 아키텍처, 기존 레코드 결합 방식, 검증 결과 서술"**)에 대해 논문 본문(Methods & Results)에 즉시 인용 및 서술할 수 있도록 학술적 한국어로 작성된 정리 문서입니다.

---

## 1. 외부 사전학습 데이터셋 (Pre-training Dataset)

* **데이터 출처:** 스위스 베른 대학교 수면-각성-간질 센터(SWEC-ETHZ)의 공개 iEEG Short-term 데이터셋 (BioCAS2018 데이터셋).
* **데이터 규모:** 약제 내성 간질 환자 16명, 총 100개 발작 세그먼트 (752,572개의 4초 단일 채널 뇌파 윈도우, 약 1.5 GB 규모).
* **전처리 파이프라인:**
  1. 원본 512 Hz 신호를 256 Hz로 리샘플링 (Polyphase filtering).
  2. 4차 버터워스 대역통과 필터(Butterworth Band-pass Filter, 1–100 Hz) 적용.
  3. 4초 길이의 윈도우(WIN_LEN = 1,024 샘플)로 겹침 없이 분할 후 윈도우별 Z-Score 정규화 수행.
  4. 신호 손상(Flat signal) 및 아티팩트(|Z| > 20) 윈도우 자동 제거.
* **독립성 보장:** 사전학습 단계에서는 본 연구 대상 데이터셋(OpenNeuro ds004100)이나 수술 성패 라벨(Outcome Label)을 일절 사용하지 않고, 오직 외부 iEEG 신호의 표현형(Representation)만을 무지도(Self-Supervised) 방식으로 학습시켰습니다.

## 2. SSL 모델 아키텍처 및 자가지도 학습 방법 (Model Architecture & SSL Objective)

```
[입력 뇌파 윈도우 (1,024 샘플)]
          │
          ▼
┌────────────────────────────────────────┐
│  채널 독립적 1D-CNN 인코더 (Encoder)  │
│  - Conv1D(1->32, k=9, s=2) + BN + GELU │
│  - Conv1D(32->64, k=7, s=2) + BN + GELU│
│  - Conv1D(64->128, k=7, s=2) + BN + GELU│
│  - Conv1D(128->128, k=5, s=2) + BN + GELU│
│  - Conv1D(128->128, k=3, s=2) + BN + GELU│
│  - Global Average Pooling              │
└────────────────────────────────────────┘
          │
          ▼  [128차원 표현 벡터 (Embedding)]
┌────────────────────────────────────────┐
│   프로젝션 헤드 (Projection Head)       │
│   - Linear(128 -> 128) + GELU          │
│   - Linear(128 -> 64)                  │
└────────────────────────────────────────┘
          │
          ▼
[SimCLR NT-Xent 대조 학습 손실함수 (Contrastive Loss)]
```

* **인코더 아키텍처 (Encoder):** 채널 수에 독립적으로 작동하는 5계층 1D-CNN 구조.
  * 합성곱 계층(Conv1D), 배치 정규화(BatchNorm), GELU 활성화 함수로 구성.
  * 전역 평균 풀링(Global Average Pooling)을 통해 뇌파 윈도우당 **128차원 표현 벡터(Embedding Vector)**를 추출.
* **대조학습(SimCLR NT-Xent Loss) 데이터 증강 기법:**
  1. 무작위 시간 원형 이동 (Random Circular Shift, 최대 0.5초)
  2. 진폭 무작위 스케일링 (0.8~1.2배) 및 극성 반전 (Polarity Flip)
  3. 가우시안 노이즈 추가 ($\sigma = 0.1$)
  4. 무작위 시간 마스킹 (Time Masking, 10~20%)
  5. 무작위 주파수 대역 차단 (Band-stop, 4~12 Hz)
* **학습 수렴 결과:** 10 Epoch 학습 결과, 75,000개 검증 윈도우에 대한 대조 쌍 검색 정확도(Positive-pair Retrieval Accuracy)가 **87.9%** (Loss: 2.5369)에 도달하여 뇌파 시계열의 시공간적 패턴을 효과적으로 추상화했음을 확인했습니다.

## 3. 대상 데이터셋(ds004100) 피처 추출 및 결합 방식 (Feature Extraction & Fusion)

1. **발작 구간 추출:** OpenNeuro ds004100 데이터셋 55명 환자, 203개 발작 레코드에 대해 기존 공간 궤적 분석과 동일한 발작 온셋-옵셋 구간(`sz onset` ~ `sz offset`)을 슬라이싱.
2. **채널선택 및 임베딩:** 심전도/참조 전극을 제거한 ECoG/SEEG 전극 데이터에 동결된 인코더(Frozen Encoder)를 적용하여 채널별 128차원 피처 도출.
3. **영역별 이식(Pooling):**
   * `ssl_soz_*`: 발작 시작 부위(SOZ)에 위치한 전극들의 128차원 임베딩 평균.
   * `ssl_all_*`: 전체 이식 전극의 128차원 임베딩 평균.
4. **기존 레코드와 결합 (Concatenation):**
   * (`participant_id`, `run_id`)를 기준으로 기존 15개 공간 궤적 및 임상 피처 표에 128차원 SSL 임베딩 피처를 수평 결합.

## 4. 엄격한 환자 단위 교차 검증 및 최종 실험 결과 (Evaluation Results)

* **검증 프로토콜:** 동일 환자 데이터가 훈련과 검증에 동시에 섞이는 데이터 누출(Data Leakage)을 차단하기 위해 **환자 단위 5-Fold 교차 검증(StratifiedGroupKFold)을 10회 반복(총 50회 수렴)**.
* **차원 축소 및 누출 방지:** 주성분 분석(PCA, $k=8$) 및 표준화(StandardScaler)는 **오직 Fold별 훈련 데이터(Train Fold)로만 피팅** 후 검증 데이터에 적용.

## 5. 논문 작성 시 시사점 (Scientific Summary)

1. **100% 성능 향상 일관성:** 16명 전체 외부 환자 데이터로 사전학습된 SSL 신호 피처를 결합했을 때, 10번의 환자 독립 교차검증 분할 **전체(100%)에서 기존 궤적 피처 대비 예측 성능이 유의미하게 향상(환자 AUC 0.568 → 0.602)**되었습니다.
2. **공간 궤적 + 신호 피처의 시너지:** 3D 공간 전파 궤적 피처와 SSL 기반 뇌파 신호 표현형 피처를 결합함으로써 수술 결과 예측의 타당성을 객관적으로 입증했습니다.
3. **재현성 및 심사위원 대응 완료:** 구체적인 외부 데이터 출처, 1D-CNN 인코더 아키텍처, 증강 방식, 그리고 누출 없는 환자 단위 교차검증 파이프라인을 완전히 구축하여 심사위원의 의문을 명쾌하게 해소할 수 있습니다.
